# Крипто-аналитик для Telegram

Бот собирает данные из нескольких источников, считает технические индикаторы,
оценивает новостной фон и выдаёт сигнал по монете: от «активно покупать» до «активно продавать».

## Источники
| Источник | Что берём |
|---|---|
| CoinGecko | цены, объёмы, история за 120 дней, тренды, капитализация, доминация BTC |
| alternative.me | индекс страха и жадности |
| CoinDesk, Cointelegraph, Decrypt, The Block, Bitcoin Magazine (RSS) | новости |
| Claude (Anthropic API) | ИИ-анализ новостей: влияние на цену, сила влияния, краткое резюме |

## Как считается сигнал
Каждый фактор даёт оценку от -1 до +1, затем взвешенная сумма переводится в шкалу ±100
(веса в `cryptobot/analyzer.py`, словарь `WEIGHTS`):

- **Тренд (25)** — цена относительно EMA20, EMA50, SMA100
- **Импульс (20)** — MACD и его пересечения
- **RSI (15)** — перепроданность (<30) / перекупленность (>70)
- **Боллинджер (10)** — положение в канале
- **Объём (10)** — подтверждает ли объём движение цены
- **Новости (10)** — оценка ИИ: как новости повлияют на цену, умноженная на силу влияния
  (слабое ×0.4, среднее ×0.75, сильное ×1). Без ключа Anthropic — подсчёт позитивных/негативных слов
- **Настроение (10)** — индекс страха и жадности (контрарно: страх = возможность)

Уверенность — доля факторов, согласных с итоговым направлением.

## Команды
- `/analyze BTC` — подробный анализ монеты (тикер, название или id CoinGecko)
- `/top` — рейтинг монет из `WATCHLIST`
- `/market` — состояние рынка
- `/trending` — монеты в тренде
- `/news` — ИИ-сводка рынка и свежие заголовки
- `/backtest BTC` — как сигналы бота сработали бы в прошлом
- `/subscribe`, `/unsubscribe` — ежедневная сводка

## Бэктест
```bash
python -m cryptobot.backtest                       # 9 монет, вся история OKX
python -m cryptobot.backtest BTC ETH --details     # подробно по каждой монете
python -m cryptobot.backtest --start 2023-01-01    # только с 2023 года
python -m cryptobot.backtest --weights trend=25,momentum=20,volume=10   # свои веса
python -m cryptobot.backtest --btc-filter 200      # торговать, только когда BTC выше SMA200
```
С `--btc-filter N` в отчёт добавляется сравнение четырёх вариантов: удержание, сигналы,
сигналы с фильтром и один фильтр без сигналов (держим монету, пока BTC выше средней).
Каждый день сигнал считается только по данным, известным на закрытие этого дня (последние 120 дней,
как в живом боте). Стратегия только покупает: вход при оценке ≥ `--buy`, выход при ≤ `--sell`,
комиссия 0.1% за сделку. Сравнение — с «купить и держать». Новостной фактор не участвует:
архива новостей нет. Данные: дневные свечи OKX (с 2018 года) и история индекса страха и жадности;
кэшируются в `.cache/backtest/` на 12 часов.

Отчёт показывает:
- доходность, просадку и коэффициент Шарпа стратегии против удержания;
- среднюю доходность через 7 и 30 дней после каждого типа сигнала и долю верных направлений;
- корреляцию каждого фактора с будущей доходностью — какие факторы помогают, а какие мешают.

Если меняете веса, подбирайте их на одном периоде (`--end 2022-12-31`), а проверяйте на другом
(`--start 2023-01-01`) — иначе результат будет подогнан под историю.

## Запуск
1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Установите зависимости и настройте окружение:
   ```bash
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env   # впишите TELEGRAM_BOT_TOKEN
   python -m cryptobot
   ```
3. Для ИИ-анализа новостей получите ключ на [console.anthropic.com](https://console.anthropic.com)
   и впишите его в `ANTHROPIC_API_KEY`. Модель задаётся в `ANTHROPIC_MODEL`
   (по умолчанию `claude-opus-5-5`; `claude-haiku-5-5` в десятки раз дешевле, но анализирует проще).
   Результаты кэшируются на 15 минут: `/analyze` — один запрос к Claude на монету,
   `/top` — по запросу на каждую монету из `WATCHLIST`, `/news` — один запрос.
4. Тесты: `pip install pytest && python -m pytest`

## Важно
Никакой бот не может давать *точные* прогнозы цены. Это инструмент, который сводит
много данных в одно место и помогает принимать решения, но сигналы часто ошибаются,
особенно на новостях и резких движениях. Перед подключением реальных денег проверьте
стратегию на истории (бэктест) и не вкладывайте больше, чем готовы потерять.
